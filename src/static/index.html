哪些网址能抓、哪些不能？

可以抓

不需要登录的公开页面：列表页、表格页、分类页、单篇文章；以及任何公开的 JSON 数据接口。

抓不到

要登录态或人机校验的站点：淘宝、京东、拼多多、小红书、微博页面。抓到的是空壳页，只给摘要不出图。

JSON 接口是什么

网址里带 /ajax/ /api/，浏览器打开满屏是 { } 的，就是接口。抓它最稳，不用解析页面。

怎么找接口

打开目标页面 → F12 → 网络 → 筛 Fetch/XHR → 找返回 JSON 的请求 → 标头里抄「请求 URL」。
